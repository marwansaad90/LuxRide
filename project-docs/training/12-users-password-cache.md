# 12 - المستخدمون وكلمات المرور والكاش

## الهدف
تغيير كلمة المرور ومسح الكاش عند الحاجة.

## المسار
`WordPress Admin -> Users -> Profile` و `LiteSpeed Cache -> Toolbox`

## الخطوات
1. لتغيير كلمة المرور افتح `Users -> Profile`.
2. اضغط `Set New Password`.
3. احفظ كلمة مرور قوية وفريدة.
4. لا تحذف حساب المدير الأساسي.
5. لمسح الكاش افتح `LiteSpeed Cache`.
6. اختر `Toolbox`.
7. اضغط `Purge All`.
8. افتح الموقع في نافذة خاصة وتحقق.

## معنى الحقول
- `Profile`: حسابك الشخصي.
- `Purge All`: مسح الكاش ليظهر أحدث محتوى.

## الحفظ والتحقق
سجل خروجاً ودخولاً بعد تغيير كلمة المرور. بعد الكاش، أعد تحميل الموقع.

## أخطاء شائعة
- مشاركة كلمة مرور المدير.
- مسح الكاش بعد كل تعديل صغير بلا حاجة.

## ما لا تلمسه
لا تحذف مستخدم المدير الرئيسي.
