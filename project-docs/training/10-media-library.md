# 10 - مكتبة الوسائط

## الهدف
رفع واختيار الصور والفيديوهات بطريقة صحيحة.

## المسار
`WordPress Admin -> Media -> Add New` أو زر `Choose from Media Library`

## الخطوات
1. افتح Media.
2. ارفع صورة أو فيديو.
3. اكتب Alt Text مناسب للصورة.
4. ارجع للسيارة أو الوجهة أو التجربة.
5. اضغط `Choose from Media Library`.
6. اختر الملف.
7. تحقق من المعاينة.
8. احفظ العنصر.

## معنى الحقول
- `Alt Text`: وصف مختصر للصورة.
- `Poster`: صورة غلاف الفيديو.
- `Gallery`: عدة صور لتجربة واحدة.

## الحفظ والتحقق
افتح الصفحة العامة وتأكد أن الصورة أو الفيديو يعمل.

## أخطاء شائعة
- رفع صور أو فيديوهات كبيرة جداً.
- استخدام صورة عمودية داخل كارت 16:9.

## ما لا تلمسه
لا تحذف ملفات وسائط مستخدمة في صفحات منشورة.
