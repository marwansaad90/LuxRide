# 11 - النسخ الاحتياطي والاستعادة من Hostinger

## الهدف
شرح النسخ الاحتياطي والاستعادة للمبتدئين عبر hPanel.

## المسار
`Hostinger hPanel -> Websites -> luxride-eg.com -> Backups`

## الخطوات
1. افتح hPanel.
2. اختر موقع `luxride-eg.com`.
3. افتح `Backups`.
4. راجع النسخ اليومية التلقائية.
5. قبل استعادة نسخة قديمة، خذ نسخة حالية إن أمكن.
6. اختر التاريخ المطلوب.
7. اختر استعادة الملفات أو قاعدة البيانات حسب المشكلة.
8. انتظر اكتمال الاستعادة.
9. افتح الموقع وتحقق.

## معنى الحقول
- `Files backup`: ملفات الموقع والثيم والإضافات والصور.
- `Database backup`: المحتوى والحجوزات والإعدادات.

## الحفظ والتحقق
بعد الاستعادة افتح الصفحة الرئيسية والحجز ولوحة ووردبريس.

## أخطاء شائعة
- استعادة قاعدة البيانات فقط عند وجود مشكلة في الملفات.
- عدم أخذ نسخة حالية قبل الرجوع لنسخة قديمة.

## ما لا تلمسه
لا تستخدم SSH كطريقة يومية للعميل. SSH للمطور فقط.
