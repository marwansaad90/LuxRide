# 15 - Google Search Console و SEO

## الهدف
شرح Google Search Console و AIOSEO للمبتدئين بدون تعديل الكود.

## المسار
`Google Search Console -> Property: luxride-eg.com` و `WordPress Admin -> AIOSEO`

## الخطوات
1. افتح Google Search Console بالحساب الذي يملك الموقع.
2. اختر خاصية `luxride-eg.com` فقط.
3. افتح `Sitemaps`.
4. أضف أو راجع رابط خريطة الموقع مثل `https://luxride-eg.com/sitemap.xml`.
5. افتح `URL Inspection`.
6. افحص صفحة مهمة مثل `https://luxride-eg.com/booking/`.
7. اقرأ حالة الفهرسة.
8. إذا كانت الصفحة سليمة، لا تطلب الفهرسة مرات كثيرة.
9. من ووردبريس افتح AIOSEO عند الحاجة لمراجعة العناوين والوصف.

## معنى الحقول
- `Property`: الموقع الذي تتابعه Google.
- `Sitemap`: ملف يخبر Google بروابط الموقع المهمة.
- `URL Inspection`: فحص صفحة محددة.
- `Page Indexing`: هل Google يستطيع فهرسة الصفحة.
- `AIOSEO`: إضافة إدارة العنوان والوصف وخريطة الموقع.

## الحفظ والتحقق
بعد إرسال sitemap، انتظر حتى تعرض Search Console حالة `Success` أو رسالة واضحة. لا تعتبر الاتصال مكتملاً بدون ظهور الملكية داخل حساب Google.

## أخطاء شائعة
- إضافة دومين قديم أو تجريبي بدلاً من `luxride-eg.com`.
- طلب الفهرسة لكل صفحة يومياً.
- تعديل كود SEO من ملفات الموقع.

## ما لا تلمسه
لا تضف روابط `luxdure.pages.dev` أو `jawadkhaled.dev`. لا تضف Review أو AggregateRating وهمي.
