# 02 - الأسعار والمسارات

## الهدف
شرح إدارة أسعار الحاسبة بدون تغيير الوجهات العامة أو التصميم.

## المسار
`WordPress Admin -> LuxRide -> Pricing & Routes`

## الخطوات
1. افتح `LuxRide`.
2. اختر `Pricing & Routes`.
3. من قسم `Update prices from Excel` نزّل `Download populated price update template (.xlsx)`.
4. عدّل أعمدة الأسعار الستة فقط، ولا تعدّل `route_code`.
5. ارفع الملف واضغط `Validate prices` أولاً.
6. تأكد أن النتيجة نظيفة وأن `routes_to_disable` يساوي صفرًا.
7. ارفع نفس الملف واضغط `Apply price update`.
8. افتح الحاسبة وجرب نفس المسار والسيارة للذهاب والذهاب والعودة.

ترتيب الأعمدة غير مهم؛ النظام يطابقها بحسب اسم رأس العمود. وضع تحديث الأسعار لا يغير أسماء المسارات أو الرسوم أو التصنيفات أو حالة التفعيل.

## معنى الحقول
- `Pickup`: موقع الانطلاق.
- `Destination`: الوجهة.
- `Sedan / MPV / Mini Van`: أسعار كل سيارة.
- `Airport fee`: رسوم المطار عند وجودها.
- `Permit`: تصريح السفر عند وجوده.

## الحفظ والتحقق
بعد الحفظ افتح `Book Now` وتأكد أن السعر الجديد يظهر.

## أخطاء شائعة
- اعتبار `Destinations` مصدر كل 320 مسار.
- تعديل سعر بدون اعتماد.
- استخدام `Full routes import (advanced)` لتحديث الأسعار فقط.
- حذف عمود سعر أو تغيير `route_code` في ملف التحديث.

## ما لا تلمسه
لا تحذف المسارات ولا تغير مفاتيح السيارات. لا تستخدم الاستيراد الكامل إلا عند تعديل بيانات المسارات كاملة، لأن المسارات غير الموجودة فيه قد تُعطّل.
