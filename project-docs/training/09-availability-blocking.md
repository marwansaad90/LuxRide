# 09 - حظر توفر السيارات

## الهدف
حظر سيارة أو كل السيارات لفترة معينة.

## المسار
`WordPress Admin -> LuxRide -> Availability`

## الخطوات
1. افتح `Availability`.
2. اختر Vehicle: all أو sedan أو mpv أو minivan.
3. أدخل Start date/time.
4. أدخل End date/time.
5. اكتب Reason.
6. أضف Notes عند الحاجة.
7. فعّل Active.
8. اضغط Save Block.
9. اختبر الحاسبة بوقت داخل نفس الفترة.

## معنى الحقول
- `all`: كل السيارات.
- `active`: الحظر يعمل.
- `inactive`: الحظر محفوظ لكنه لا يؤثر.

## الحفظ والتحقق
تأكد أن الحجز المتعارض لا يمر، وأن وقتاً آخر يعمل.

## أخطاء شائعة
- إدخال وقت نهاية قبل وقت البداية.
- نسيان إلغاء الحظر بعد عودة السيارة.

## ما لا تلمسه
لا تستخدم الحظر لتغيير الأسعار.
